# ABIR.OS — Personal Developer Operating System

A desktop-inspired personal portfolio for Abir Agarwal, with responsive mobile layout.

## Files
- `index.html` — portfolio structure
- `style.css` — visual design and responsive layout
- `script.js` — interactive desktop apps and portfolio content

## Deploy / update on GitHub Pages
Upload all four files directly to the root of the `abiragarwal.github.io` repository and commit the changes.

## Included content
- About, skills, credentials, contact, and project windows
- Nova personal project
- TantraYantra independent technology venture and PeopleLens first product
- Responsive phone layout

External links and product status should be kept current as the projects evolve.
