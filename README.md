# ABIR.OS Desktop v3
A desktop-style personal portfolio for Abir Agarwal.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Wait for the boot sequence. Double-click desktop icons or use the dock/Applications menu.

## Interaction
- Real desktop layout with desktop shortcuts, top system bar, dock and app launcher.
- Open About, Projects, Skills, Credentials, GitHub, Terminal and Contact windows.
- Drag windows by their title bars; minimize, maximize and close them.
- Terminal commands: `help`, `about`, `projects`, `skills`, `github`, `contact`, `whoami`, `clear`.
- `Ctrl+K` opens the app launcher; `Esc` closes it.
